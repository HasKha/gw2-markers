# Markers for gw2 blishhud pathing module

## Requisites
- Install Blish HUD from https://blishhud.com/
- Install the Blish HUD **Pathing Module**.

## Setup
- Download the latest haskha_markers.zip in [releases](https://github.com/HasKha/gw2-markers/releases)
- Do not extract the zip.
- Copy or move the folder to `~/Documents/Guild Wars 2/addons/blishhud/markers`
- Disable and enable the pathing module, or relaunch blishhud, or relaunch gw2.

## Tips
- To reduce overlay lag, go into blishhud -> Overlay Settings -> Blish HUD Graphics Settings -> Set "Frame Limiter" to "Match Monitor Refresh Rate"
- To capture the markers in OBS, go into blishhud -> Overlay Settings -> Enable "Show in Taskbar". Then Add a new Game Capture to OBS and add BlishHUD. Make sure to enable "Allow Transparency" in its properties.
